NONHLE'S COSMETICS: DEPLOYMENT CHECKLIST (Namecheap cPanel)
============================================================

BEFORE YOU UPLOAD
[ ] Back up the current site: in File Manager, compress public_html and download the zip.
[ ] If you're replacing the old site, delete its old files from public_html:
    - upload_handler.php   (the old upload script; it must not stay on the server)
    - the old uploads/ folder, if you don't need those images
    - any old .htaccess, which the new one replaces

UPLOAD (easiest: upload the zip and extract it on the server)
[ ] In cPanel → File Manager, open public_html.
[ ] Upload nonhle-cosmetics-site.zip, right-click it → Extract, and extract into public_html.
    The files must sit directly in public_html (public_html/index.html), not in a subfolder.
    If you used GitHub's "Download ZIP" instead, it adds a folder such as redesigned-nobuhle-main/.
    Move that folder's contents up into public_html.
[ ] Delete the zip from public_html after extracting.
[ ] Hidden files: File Manager → Settings → tick "Show Hidden Files (dotfiles)".
    Check that .htaccess, uploads/.htaccess, admin/.htaccess and admin/storage/.htaccess are all there.
    (Extracting on the server keeps them. Unzipping on Windows first and re-uploading can lose them.)
    README.md and this checklist can stay; .htaccess blocks them from the web.

PERMISSIONS
[ ] Folders: data/, uploads/, admin/, admin/storage/ → 755
[ ] Files: data/content.json → 644

STRAIGHT AFTER UPLOAD (do this first)
[ ] Open https://nonhle-cosmetics.store/admin/ and create the editor password.
    Until it's set, anyone who opens /admin/ could set it.
[ ] Give the password to the owner privately. Don't email it or write it in a file on the server.

CHECK THE SITE
[ ] Home page loads with photos, products, services and the gallery.
[ ] Add two products to the basket → "Send order on WhatsApp" opens WhatsApp with the order.
[ ] Book a service → WhatsApp opens with the booking details.
[ ] Contact form → WhatsApp opens with the message.
[ ] Try it on a phone too: open the menu, add to basket, use the floating WhatsApp button.

CHECK THE EDITOR
[ ] Change a price, save, and refresh the site to see it.
[ ] Upload a product photo and a gallery photo, save, and check the site.
[ ] Log out and back in.

CHECK THE SECURITY RULES (these depend on the server, so test them live)
[ ] https://nonhle-cosmetics.store/admin/config.php  → should show 403 Forbidden
[ ] https://nonhle-cosmetics.store/admin/lib.php     → should show 403 Forbidden
[ ] https://nonhle-cosmetics.store/README.md         → should show 403 or 404
[ ] https://nonhle-cosmetics.store/uploads/          → should not list files
[ ] https://nonhle-cosmetics.store/upload_handler.php → should show 404 (old script removed)
    If any of these load instead, ask Namecheap support to enable .htaccess overrides (AllowOverride).

HTTPS
[ ] SSL is active (Namecheap's free PositiveSSL / AutoSSL) and http:// redirects to https://.

BEFORE LAUNCH: CONTENT
[ ] Real prices set (0 shows "Price on request").
[ ] Deep Conditioner photo added; Hairgrowth Oil and Shampoo photos replaced with larger ones.
[ ] About text checked by the owner.
[ ] Opening hours, location and Instagram filled in under Settings, if wanted.
